# 执行器与中断时序

在功率输出、逐周期保护、继电器、故障/维护恢复、复位或 ISR 竞争审查时读取。只核查本项目存在的功能；优先级、阈值、状态名称、寄存器顺序及实现位置均来自其硬件与需求，不由技能提供默认值。代码举例见 [examples.md](../examples.md)。

## 1. 动作仲裁与保护可达性

列出必要的动作表：`动作/资源 | 写入者 | 上下文 | 正常/紧急 | 准入条件 | 清除/恢复权限`。

正常动作应有明确仲裁，避免多个独立决策者争写。必须立即执行的紧急保护不能为了统一软件出口而等待低优先级处理；异步上下文中的具体工作须符合其时间预算。软件路径不代替硬件要求的快速保护。

按实际入口检查禁止条件是否真正生效：

| 入口类别 | 要核对的关系 |
|---|---|
| 首次启动、自动启动、重新启动 | 当前故障、配置、测量和维护条件是否被读取，旧许可是否可复用 |
| 非零控制动作 | 从资格检查到硬件提交之间，新故障能否被旧命令覆盖 |
| 开关或继电器动作 | 执行时资格是否仍成立，停止请求是否能及时撤销待执行命令 |
| 维护、复位、升级及退出 | 失败分支和恢复路径是否绕过规定的禁止条件 |

只有产生禁止状态却无消费者，不证明保护已实现。先核对它是否是批准要求、是否有等价保护及实际可达后果；未使用的声明不自动构成严重故障。

## 2. 首次动作、停止和恢复

从当前源码及硬件配置还原有序事件、执行上下文和可抢占窗口：

- 首次可能输出能量或产生危险动作的具体时点；所需保护何时建立。
- 控制值到实际动作的关系，包括极性、更新、缓存、死区和停止状态等适用配置。
- 故障发生、即时关断与后续记录之间的关系；唯一保护是否被提前撤销。
- 暂停、过期、维护或故障后的恢复资格；旧控制结果、旧操作请求和保留计算历史是否能直接生效。

保留历史状态可以合理，但不应跳过当前工程要求的恢复条件。是否需要首拍限制、变化速率或重建历史，由项目合同和证据决定，不能从别的产品迁入数值或控制策略。

数值处理与时间屏障分别核对。限幅、换算可以合并；数据时效、故障代次、写前检查、硬件更新确认、写后与恢复中断后的检查可能保护不同窗口。简化前必须证明这些窗口仍受保护。

同一个动作依据的测量、故障、配置和许可应构成相容的决策。重复评估或中断改变条件后，所有被共同使用的结果需要刷新或由等价一致性机制保护；不强制新增某个结构体或版本字段。

## 3. ISR 与并发交接

列出异步入口中的提前返回条件，追其设置、清除和相对物理动作的时点。资格读取与允许动作之间若可被中断，需检查事件是否丢失或较新的否决是否会被覆盖。

只有当前硬件可抢占、锁存、清标志和读取语义核实后，才确认竞争及后果。`volatile` 不能自动修复多操作事务。硬件锁存、短临界区、原子操作、队列或单向事件均可按目标支持和预算选择，不强制某种实现。

检查适用关系：

- 故障/事件的发布、消费和清除交错；旧清除不得覆盖新事件。
- DMA/采样缓冲写入、冻结、发布和消费；身份、时间、有效性与数据相容。
- 驱动缓存、寄存器设定和实际生效之间的差异。
- 停止/恢复、维护进入/退出与普通控制同时发生时的仲裁。
- 临界区保存并恢复原中断状态，范围与耗时有界。
- 硬件等待的预算、超时和安全失败路径。
- 快速路径的运算、拷贝、组帧和回调是否有界；不能被 Flash 操作、阻塞日志或其他不适合该上下文的工作拖延。

按保护响应、控制截止时间及通信负载核对优先级、嵌套和共享资源。所有中断同级或单纯提高优先级都不能替代分析。目标存在非易失存储忙等待时，要追完整调用链、常量和编译辅助代码；只迁一个入口不能证明整条链安全。

按实际硬件追异步源使能、中断控制器/路由、入口绑定、当前链接处理、事件交接和消费者。不预设某种控制器或向量名；默认声明与实际链接结果分别取证。

## 4. 功率场景中的适用检查

**逐周期保护存在时**：分别核对触发来源、硬件动作、软件统计、锁止及恢复条件。停止后的旧事件、旧控制结果或并发任务不得绕过既定恢复要求。统计窗口、扣分和恢复时机从本项目取得，不默认规定由 ISR 还是任务恢复。

**预充或延迟合闸存在时**：追请求资格、动作前等待、测量时点、压差/方向条件、执行、稳定/反馈、超时与失败动作。不同模式是否共享资格取决于需求；共享操作代码不意味着全部条件相同。要求等待后重新确认的条件，不能用等待前旧数据替代。

GPIO 锁存或引脚读回与机械触点是不同事实。只有硬件确有相应反馈能力，且数据有效性符合合同，才能声明物理动作已确认。

**复位存在时**：分别覆盖实际软件入口、看门狗、掉电以及引导交接。软件可控复位可以有清理步骤；硬件复位或掉电不能假定会执行这些步骤。核对外设、引脚、外部驱动和供电默认态，以及重新准入条件。

缺电路、器件资料或当前实测时列具体缺口，不从控制值为零或某个复位调用推断物理无脉冲，也不推断必然失控。

## 5. 反例与实测边界

按实际改动选择必要验证：首次危险动作时故障、检查与提交间抢占、读事件与清空间新事件、停止后旧请求、连续/间歇保护、等待后的新数据、软件与硬件复位。

主机测试可验证状态和注入顺序，当前目标构建可核对符号及链接；真实极性、采样/中断时刻、保护延迟、机械反馈及负载波形需要相应硬件证据。记录预期、实际、覆盖条件和未执行项；运行过测试不等于测试通过，更不等于完整实板验收。
