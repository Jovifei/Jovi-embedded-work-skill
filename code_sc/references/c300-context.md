# C300 约束示例

仅在当前任务确认为 C300 重构链时读取。本页记录 2026-11-25 整理的用户约束与需重新核实的实现合同，用于避免把参考工程 B 当产品基线；它不是当前固件通过证书，也不是其他项目的默认参数。

先记录原工程、参考 B、当前修改版三份身份；核对用户最新明确要求与当前源码，冲突时说明具体差异，不自行按本页覆盖后续已批准的变化。下面的历史未完成项不能直接报成本次 BUG。

## 1. 简洁职责与原库

| Owner | C300 责任 |
|---|---|
| main | 初始化、时间/节拍、前台串行顺序和系统健康判断 |
| sample | 原码交接、零点校准、换算、滤波、极值、功率和有身份的快照 |
| charge | TC/CC/CV/FC、复充/限时、限功率、原 HT32 库调用与复位、Demo 档案/候选和相关计量 |
| protection | 故障、锁止/恢复资格、供电/存储禁止及输出许可 |
| output | 正常 PWM/功率继电器统一审核提交、首拍/斜率、预充、维护关断 |
| debug | 只读诊断、限量输出、统计与日志 |
| mmi | 按键/面板/通信命令语义、配置请求与完整档案提交、显示/OTA 交互 |

六类应用职责不限制整个工程只有六个文件。LED、按键、配置、变量、启动、中断及已有驱动等支持文件可以保留；不因逻辑责任再套多层 manager/service/coordinator。

保留 `HT32_Mppt_Solar.h` 对应的原库，将计算和复位入口集中 charge，不吸收 B 的 MPPT 搜索算法，不强制新增独立算法文件或转发层。确认库版本/hash、ABI、结构体布局、单位、调用频率和状态语义；未知私有字段不能猜写。MCU 移植需另核处理器/编译器 ABI 与库支持，驱动隔离不能证明原库在任意平台可用。

普通命令由应用调驱动，真实异步事件由 ISR 上行。前台 output 统一正常功率提交；驱动 ISR 仍立即关断。当前 CBC 合同由前台新候选走恢复，ISR 不改库 Duty 或恢复 MOE。

## 2. 应保留的产品基线

| 项目 | 已明确基线/边界 |
|---|---|
| 当前目标 | HT32F65240；换 MCU 单列适配与验证 |
| PV 额定功率/最大电流 | 300W / 10A |
| 电池 CC / 涓流 | 6A / 2A |
| PV 工作范围 | 13–55V |
| 库比较值 | 108–1092、周期 1200；真实引脚导通关系按原硬件合同 |
| 普通电池 | 保留 AN300 的 12 档、单位、温补和保护关系 |
| B 工程参数 | 不随吸收实现迁入 165W、7A、5A、8–90% 或独立 90V/95V 门 |
| Demo 平台 | 计划已明确为 Lead 48/60/72V；与普通化学档案独立 |
| Demo 默认目标 | 57.8/72.3/86.8V，对应当时 Lead CC→CV；独立目标配置需查当前实际完成状态 |

独立 Demo 目标是数据责任，不要求新应用模块或提前扩展交互/协议。修改目标时同时核对控制上下窗、功率/电流、软件保护、硬件比较器与可工作范围。

## 3. 需逐版验证的实现合同

以下用于发现“结构整理”中隐藏的行为变化；不把数值当通用安全推荐。

| 项目 | 2026-11-25 收录的合同 |
|---|---|
| IRQ | CMP=0，MCTM 更新=1，tick/UART=3；检查实际开启、优先级配置与嵌套 |
| PWM 首拍 | 关波 1201，经两次成功自然更新到 1092，再经两次并复核使能；两段各 3ms 超时 |
| 运行斜率 | 合格新毫秒服务中，增大导通方向最多减 6 比较计数；另一方向也受服务门约束 |
| CBC | 500 积分；ISR 关断、前台新候选恢复；停波与首个恢复周期不扣分 |
| 普通预充 | 请求压差 2V；停波后新样本；PB4 前 3V 与单向资格；100ms 后 3.5V；阶段 150ms 超时 |
| Demo 合闸 | 保留已明确例外；output 执行前仍受同轮 STOP、保护和维护否决 |
| PA15 | 当前异步 Boost 合同为低电平；不能据此宣称电感始终 DCM |
| 样本时效 | 当前 1ms 门需要实际执行时间/负载证据，名义 tick 不够 |
| BL 冷启动 | 有效完成记录、整镜校验、向量/入口资格，须配套工厂首装 |

预充表仅给已记录阈值，未定义精确不等式、极性或所有顺序；这些必须以已批准合同与当前源码取证，不能从数字自行推导。改变首拍/斜率等必须登记行为变化，并验证候选与实际 CCR 轨迹、限流/限压及闭环稳定性。
