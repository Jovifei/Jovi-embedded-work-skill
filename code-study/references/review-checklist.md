# 交付复审清单

## 正文（逐章，不只看目录）

- 按实际阶段/功能组织，learning不是目标和链接清单；先有完整样章再扩展。
- 开始情况、原因、动作、实际判断、成功和失败/超时、下次调用都讲清。
- 术语先翻成动作；原函数/状态名留在旁边。不存在堆Owner/退避/合闸却不解释的段落。
- 图节点与真实模块/函数对应，边有条件和单位；正文教读图。不同状态机/中断/硬件没有混成串行链。
- 参数有定义和实际使用依据；算例可复算，假设非实测；编译关闭的功能不写当前已启用。
- 原函数第1节完整且无教学改写，第5节解释不是语句转录。模块和函数页指回学习正文。
- 自测附答案，用户进度未擅自改为已掌握。

## 文件与阅读体验

- 源码快照字节/哈希与当前基线一致；旧文档和新实现不混用。
- 学习子目录、图、答案、源码全被递归索引。过期入口同步更新，个人笔记保留。
- `file://`打开不用联网；搜索一个真实正文词有结果，罕见不在文档中的词显示无结果。
- 点击阶段文章/函数/源码可阅读，表格、代码和details答案未丢；源码行定位正确，浏览器后退能回文章。
- 图片放大及关闭、上一章/下一章、390px窄屏与桌面都实际操作；无源码/HTML注入执行。
- 关键流程图逐张看，中文无方框、文字不裁剪、箭头不遮挡；截图检查不等于图义已核对。

## 完成证据

机械检查、语义逐章复审、浏览器实测、目标固件/实机测试分开列。报告写命令、结果、内容摘要和未运行项；不能把0个搜索结果或缺浏览器当PASS。新改动必须重新运行相关检查，最终交付的文件才是受检文件。源码没改要用对照证据，不凭记忆宣称。
