# 多语言符号发现边界

不同语言的函数/方法发现能力不同。优先使用项目已有编译数据库、语言服务器、编译器AST、Tree-sitter或ctags；记录工具版本和构建条件。

- C/C++：处理static同名函数、宏函数、头内联、条件编译、弱符号、ISR向量、函数指针注册与分发。
- Python：区分函数、方法、装饰器、动态导入和猴子补丁；静态扫描不能证明运行时目标。
- Rust：区分trait实现、泛型、宏展开和条件编译feature。
- JS/TS：区分函数、方法、闭包、动态import和事件回调。
- SQL/脚本：按可见存储过程/函数/任务边界记录；动态字符串目标列未解析。

解析失败的文件仍留在覆盖分母，标明失败原因和人工边界。未知回调或动态目标不得画成确认实线。
