# 调用示例

以下是给Codex的提示词，不是Shell命令。先通过`$code-study`明确选择技能。默认不自动触发，避免普通代码问答意外生成整套书。所有任务直接写入目标项目docs/code-study；不生成ZIP，不让用户下载解压。

## 当前项目完整制作

```text
$code-study
直接在当前项目 docs/code-study/<本次源码基线>/ 创建完整代码学习资料的真实文件。
按实际版本、提交与源码摘要命名book-id；不要只输出目录、模板或计划。
先读取实际源码与Git状态；保留我的暂存和未提交修改，不切回旧main。
正文全部Markdown，仅index.html保留离线全文搜索。
逐模块、逐函数解释逻辑、参数、调用者、被调者、跨模块数据/状态交接；
每函数第1节先完整展示原函数体与原注释，不新增学习注释；第5节再用真实片段、中文学习注释讲作用与为什么，拒绝逐行语句清单。
配SVG与DOT。增加核心算法+业务状态联合专题，以及逐阶段学习和自测答案。
保留必要source_snapshot作为只读依据，不包含SDK、密钥、字体和构建产物。
核对覆盖、哈希、链接、图与搜索；语义复审单列，没跑的测试明确写未跑。
在项目目录就地完成验证，报告README、learning和index.html路径。
不要生成ZIP/TAR，不输出下载链接，不要求我搬运文件。
这次不改产品源码，不提交远端。
```

## 嵌入式工程重点

```text
$code-study
解析本地当前固件，重点覆盖主循环/ISR、采样与DMA、状态机、算法、PWM最后执行、Relay、故障挂单与恢复、串口STOP、Flash和看门狗。
区分请求值、寄存器写入与真实物理输出；不擅自改阈值或打开门禁。
宏与构建变体以本地实际工程为准；缺SDK/原理图就标未知，不能套旧版本。
```

## 将已有函数文章升级为“先看原函数，再讲解”

```text
$code-study

第1节必须完整展示该函数的原函数头/原注释与完整函数体，保持真实缩进、条件编译、所有分支与return；第1节不要加入学习注释。
后续章节顺延，第5节保留注释式代码解释。
以该书自己的source_snapshot为证据，不修改source_snapshot或产品源码。
更新搜索、链接和语义复审。
```
