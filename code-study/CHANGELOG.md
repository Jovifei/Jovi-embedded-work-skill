# code-study Changelog

## V2.0.0 — 2026-09-29

- 将 learning 从阅读任务表提升为按运行阶段与功能组织的完整教程：口语动作、条件参数、跟读例子、失败去向、图和答案。
- 保留完整原函数/原注释在前、代码解释在后的查询层；增加教学示例和逐章复审要求。
- 将唯一HTML从搜索页升级为本地Markdown阅读、搜索、图放大、源码定位；不生成每函数HTML。
- 修复子目录文章漏索引、内部 `**/` 漏匹配根层源码、失败退出码、检查时掩盖旧索引、浏览器和完成工具摘要口径不一致。
- 浏览器检查要求真实正文命中；缺浏览器或环境策略阻断标NOT_RUN。HTTP预览不能代替file://验收。
- 默认项目目录交付不变；只在本次明确要求时归档/提交。工具、规则及示例不附带产品固件。

## V1.3.0 — 2026-09-16

- 新增到 `Jovi-embedded-work-skill` 集中管理仓库。
- 默认直接在目标项目 `docs/code-study/<源码基线>/` 生成，不打包 ZIP。
- 函数页阅读顺序固定为：第1节完整原函数体与原注释；第2～4节职责/参数/调用；第5节注释式代码解释；后续流程图、并发、算例、边界和自测。
- 第1节禁止新增学习注释、删分支或改格式；第5节禁止机械的“Lxx执行语句/循环继续条件”清单。
- 正文只用 Markdown；唯一 HTML 是离线全文搜索。
- 保留模块、函数、核心专题、分阶段学习、SVG/DOT、source_snapshot 与分层验证。

## V1.2.0
