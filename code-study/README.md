# code-study

**Version: V1.3.0**

在当前项目 `docs/code-study/<源码基线>/` 直接生成可学习、可追溯的源码学习资料。正文为 Markdown，流程/调用图为 SVG＋DOT，仅保留一个离线全文搜索 HTML。

## 函数页固定阅读顺序

1. **完整函数体与原注释**：先看真实函数，不插入学习注释、不省略。
2. 函数职责与执行上下文。
3. 参数、返回值与副作用。
4. 调用者与被调用者。
5. **代码解释**：按逻辑块引用真实代码并加入中文学习注释，讲清做什么、怎样做、为什么这样安排。
6. 逻辑流程图。
7. 状态读写与并发。
8. 参数算例/一拍跟踪。
9. 失败、边界和再次调用。
10. 阅读自测。

调用 `$code-study` 后默认只修改项目 `docs/code-study/`，不改业务源码、不生成学习资料 ZIP、不自动提交远端。
