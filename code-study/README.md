# code-study 2.0.0

把工程讲成“跟着设备运行读代码”的学习书，不是只有函数目录和阅读清单。

入口：[SKILL.md](SKILL.md) · [学习正文设计](references/learning-handbook.md) · [安装与调用](INSTALL.md) · [更新记录](CHANGELOG.md)

默认输出：`docs/code-study/<实际源码基线>/`。Markdown正文、阶段目录、SVG/DOT、模块/完整函数查询、源码快照和一个离线阅读搜索入口。用户明确要求附件/归档时才额外打包；不改固件、不默认提交。

```text
$code-study 基于当前工作区重做学习文档。按实际运行阶段分组，用口语讲解，
重点解释启动、状态机、等待失败、中断和参数边界。不要只列阅读任务，
保留完整函数原代码，提供离线阅读、图放大和源码定位。
```

2.0.0把学习正文设为首要交付，修正阶段子目录索引遗漏、浏览器空结果伪通过和验证摘要不一致。逐章语义质量仍需要真实读源复审，不能由脚本证明。

产品说明、参数台账和运行规格请用相邻的 [`product-doc`](../product-doc/SKILL.md)；选择方法见 [两种文档技能](../DOCUMENTATION-SKILLS.md)。
