# 接口、所有权与状态

处理职责迁移、接口、共享状态、预览或缓存时读取。以下是判断维度，不规定模块数、函数名称或状态结构。

## 职责与依赖

先确认谁产生事实、谁维护状态、谁决策、谁执行、谁消费结果，以及各自允许的副作用。一个实现可以承担多个相容职责；需要独立维护或验证的职责也可以分开。不能由角色表直接推导必须新增文件。

边界按实际合同判断：底层实现不应为了通用硬件操作解释上层业务私有状态；调用方不应绕过被调用方的状态更新规则。回调不能掩盖循环依赖或任意共享写入，普通函数也不必一律改成事件。

保持当前运行模型。裸机循环、RTOS 任务、中断内有界控制、事件处理都可能合法；是否拆分、嵌套调用或异步交接，依据时限、重入、堆栈、状态与调用者合同确定。函数叫“任务”并不自动证明它只能由某个入口调用。

安全动作的最终批准与提交责任要明确，普通入口遵守同一仲裁；紧急路径按系统时限处理。无需预设一个统一输出文件，也不能只凭多个写点认定责任失控。

当要求更换平台时，识别不可移植类型、寄存器访问、时钟/中断假设和编译器扩展，选择满足范围的最小隔离接口。目录名称不能代替依赖核对。

外部库按实际保留或迁移合同处理。不能用自有分层偏好重定义固定 ABI，也不能因存在库就默认其状态归属、复位入口或算法不可更换。

## 接口选择

先查实际数据需要、变化频率和对象寿命。标量、既有只读快照、稳定对象或窄接口均可；不要无必要暴露可变私有状态，也不要为了窄接口复制大量状态。

改接口时列出完整旧/新签名及全部活动消费者。必要说明如下：

| 合同 | 核对内容 |
|---|---|
| 责任与调用 | 状态维护者、允许入口、实际调用链 |
| 执行时机 | 中断/任务/事件等上下文，顺序、频率、重入与最长耗时 |
| 输入 | 来源、单位、值域、有效期、配置或采样身份 |
| 输出 | 返回值、输出参数及失败时保留或修改的内容 |
| 副作用 | 状态推进、事件消费、硬件、持久化及读后清除 |
| 内存与兼容 | 对象寿命、别名、大小/对齐、序列化与调用约定 |

参数顺序和命名沿用项目约定；不套用固定的“上下文、输入、时间、输出”模板。返回值和输出参数若表达不同层次结果，应分别说明，不能按形式重复直接删掉。

公开合同只暴露真实调用者所需内容；内部计算状态保持适当封装。复位或诊断接口有合法消费者时保留其语义，不为了形式上的私有化删掉必要能力。

## 生命周期与并发

按本次相关状态，列初始化、第一次合法使用、变更、失效、清理和恢复规则。状态实例不能保留生命周期短于自身的悬空指针。

逐项判断不同入口应保留、重置或失效什么。不要把所有处理合并成含义模糊的统一重置，也不要未经合同清空应跨阶段保存的状态。

共享与同步从真实执行模型推导：单写者模型可以保留；多写者需要权限和仲裁；多字段快照需要一致交接；事件不能被取出/清除窗口中的新事件覆盖。volatile 不保证复合操作原子性或跨字段一致。

使用临界区、锁、原子交换、缓冲或消息机制时说明保护对象和生效边界。保存并恢复既有中断状态，不在中断上下文等待阻塞锁，不把整个长业务过程放入屏蔽区。

## 数据、预览与缓存

共用计算前核对输入、时点、单位、有效性和计算方法；相同数值可能属于不同语义。即时事实、历史累计和限制后的结果不能为了“单一来源”强行合并。

只有当前需求要求分离的模式，才重组其专属流程与状态。简单分支可留在一个函数，重复入口也不证明已有职责分离；用实际读写和调用说明收益。

约定只读的计算检查实际别名与间接调用，临时对象中的指针可能仍修改正式状态。若修正这一写入会改变结果，应列为行为修复，不能冒充等价去重。

缓存不是默认架构。先确认收益，随后列出会影响结果或资格的全部输入、配置、时间、状态和有效性，以及何时更新、失效或重算。配置固定部分可以在完整提交后派生，实时部分按其真实依赖更新。

相同采样编号或相同最终限值不证明缓存有效。已有测试对照路径不得未经批准变成生产拒绝或停机条件。

## 语义与数值

分别说明事实、许可、请求、事件和拒绝原因。互斥模式可以显式表达，布尔量可以表示独立事实；选择服从语义而非类型数量。

零值、无效、未启用和停止含义按当前协议与实现核对。外部编码需要兼容时保留，内部迁移应有消费者和旧值转换方案。

连续时间和连续观测分别定义；首个端点、缺失区间、无效数据和回绕要有规则，不能拼接出不存在的连续资格。

推导中间运算宽度、符号、量纲和上界，核对截断、饱和、窄化、计算顺序与回绕。需要扩宽时在相关运算前进行，不以结果类型代替中间值证明。

## 删除与简化

删除状态或接口前识别控制、持久化、协议、授权遥测、内部历史和测试等消费者。内部积分、缓存或事务记忆即使不导出也可能必须保留。

仅为旧测试暴露的冗余镜像可以在授权下收口，并让测试观察真实行为；有外部兼容合同的镜像或接口按约定迁移。诊断用途不能仅靠名称判断。

短函数按责任保留或合并：有独立事务、硬件时序、平台隔离、复用或验证价值即可成立。返回值看似恒定时先核对全部分支及调用者，不能删掉有意义的等待、失败或时序屏障。

新增状态、动作或否决必须接到实际消费者；验证覆盖相应危险入口和恢复入口，入口名称由当前工程确定。
